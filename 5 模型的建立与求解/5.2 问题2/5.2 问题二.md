# 5.2 问题二：确定外延层厚度的算法设计与求解

问题一建立了"条纹位置给相位（含 $nd$ 乘积）、条纹幅度给折射率（只含 $n$）、两者联立解耦"的两光束干涉模型。问题二的任务是：**依据该模型设计确定外延层厚度的算法**，对附件 1（入射角 $10^\circ$）、附件 2（入射角 $15^\circ$）的碳化硅晶圆片实测光谱给出厚度计算结果，并分析结果可靠性。

## 5.2.1 算法设计

### 1. 算法总体流程

以问题一模型为基础，算法分为六步，流程如下。

```
数据读取与预处理 → 干涉峰谷检测 → 包络线法反演折射率 n(σ)
    → 相邻峰谷法求解厚度 d_j → 全谱拟合精化（交叉验证） → 可靠性分析
```

其中，第 3、4 步是核心：第 3 步由条纹**幅度**给出折射率（只含 $n$），第 4 步由条纹**位置**给出厚度（含 $nd$ 乘积，$n$ 已知后即解出 $d$）。第 5 步为可选的精化与交叉验证，第 6 步负责给出结论的可信度。

### 2. 步骤一：数据预处理

附件数据第 1 列为波数 $\sigma$（$\mathrm{cm}^{-1}$），第 2 列为反射率 $R$（%）。预处理包含两点：

1. 剔除首点伪零值：附件每份数据第 1 个点（$\sigma=399.67\ \mathrm{cm}^{-1}$）反射率为 0，是仪器零点填充伪迹，直接剔除；
2. 确定可靠测量区：碳化硅在 $780\sim1030\ \mathrm{cm}^{-1}$ 存在残余射线带，该波段反射率饱和于 $93\%\sim95\%$、干涉条纹被截断失真（见 5.1 的可靠性检验）；同时 $1200\ \mathrm{cm}^{-1}$ 以下条纹受强背景色散影响明显偏离两光束模型（详见 5.2.4）。故取 **$1400\sim2500\ \mathrm{cm}^{-1}$** 作为可靠测量区，该区间条纹周期性良好、折射率色散平缓，模型与数据吻合最佳。

### 3. 步骤二：干涉峰谷检测

对可靠区内的反射率曲线，用局部极大/极小识别干涉条纹的峰与谷。实测数据存在仪器噪声，直接判读会产生大量假极值，故引入显著度过滤：仅保留相对两侧谷/峰高出（或低出）超过 $1\%$的极值点。实现上采用 $signal.find\_peaks$ 算法，对 $R$ 和 $-R$ 分别求峰与谷，再按波数合并排序，得到交替排列的极值序列 $\{(\sigma_i, R_i, \mathrm{type}_i)\}$。

附件 1 检测到极值 $25$ 个（峰 $12$、谷 $13$），附件 2 检测到 $23$ 个（峰 $11$、谷 $12$），且两份附件的峰谷位置一一对应，说明这些是真实的干涉条纹而非噪声。

### 4. 步骤三：包络线法反演折射率

这一步骤利用条纹的幅度（峰有多高、谷有多深）反演折射率。核心思想是：峰谷高度取平均恰好消去光 2 的贡献，把只由空气—外延层界面决定的信息"分离"出来。下面给出完整推导。

**（a）两光束叠加的反射率。** 由问题一两光束模型，反射率可展开为

$$
R=|r_{01}+B\,\mathrm{e}^{\mathrm{i}\phi}|^2
 =r_{01}^2+B^2+2r_{01}B\cos\phi,
\tag{9}
$$

其中 $r_{01}$ 为光 1 的振幅（空气—外延层界面反射系数），$B=t_{01}r_{12}t_{10}A$ 为光 2 的振幅系数，$\phi$ 为两束光的相位差。

**（b）峰、谷处的反射率。** $\cos\phi$ 在 $+1$ 与 $-1$ 之间摆动，反射率随之在极大与极小之间摆动：

$$
R_{\max}=(r_{01}+B)^2,\qquad R_{\min}=(r_{01}-B)^2.
\tag{10}
$$

式(10)成立要求 $|B|<|r_{01}|$（光 2 弱于光 1），其成立性由 5.2.4 用实测数据直接验证。

**（c）开平方还原振幅，取平均消去光 2。** 反射率是振幅的平方，先开平方把峰、谷还原到振幅层面：

$$
\sqrt{R_{\max}}=r_{01}+B,\qquad \sqrt{R_{\min}}=r_{01}-B.
\tag{11}
$$

在振幅层面，光 2 的贡献在峰处为 $+B$、在谷处为 $-B$，幅度相等、符号相反。二者取平均，$B$ 恰好正负相抵：

$$
|r_{01}|=\frac{\sqrt{R_{\max}}+\sqrt{R_{\min}}}{2}.
\tag{12}
$$

**（d）由 $r_{01}$ 反演折射率。** $r_{01}$ 只由空气—外延层这一个界面的折射率决定（近垂直入射的菲涅耳公式）：

$$
n=n_0\frac{1+|r_{01}|}{1-|r_{01}|}.
\tag{13}
$$

式(13)表明，本步骤所得 $n$ **与厚度 $d$、衬底折射率 $n_s$、吸收衰减 $A$ 全部无关**——光 2 的痕迹已被峰谷平均消除。

**（e）逐对操作得 $n(\sigma)$ 曲线。** 对可靠区内每一对相邻峰谷重复步骤（b）—（d），即得折射率随波数的离散序列 $n(\sigma)$。由于相邻峰谷对间隔很小，相邻 $n$ 值变化平缓，用一次多项式最小二乘拟合得到光滑的 $n(\sigma)$ 曲线，供步骤四分别在峰、谷波数处取值。

### 5. 步骤四：相邻峰谷法求解厚度

对可靠区内每个相邻峰谷对，由问题一模型求解厚度：

$$
d_j=\frac{1}{4\left|\sigma_{v,j}\,n(\sigma_{v,j})\cos\theta_{1,v,j}-\sigma_{p,j}\,n(\sigma_{p,j})\cos\theta_{1,p,j}\right|},
\qquad
\cos\theta_1=\frac{\sqrt{n^2-n_0^2\sin^2\theta}}{n}.
\tag{14}
$$

式中 $\sigma_{v,j}$、$\sigma_{p,j}$ 分别为第 $j$ 对峰、谷的波数，$n(\sigma_{v,j})$、$n(\sigma_{p,j})$ 由步骤三的光滑曲线分别在峰、谷波数处取值，严格计入相邻峰谷间的折射率色散。
对 $N$ 个峰谷对得到 $N$ 个 $d_j$。单个峰谷的波数判读存在随机误差，为减小其影响，取中位数作为厚度估计，并用中位数绝对偏差刻画离散程度：

$$
\hat d=\operatorname{median}\{d_j\},\qquad \delta d=\operatorname{median}\{|d_j-\hat d|\}.
\tag{15}
$$

### 6. 步骤五：交叉验证

以步骤四所得 $\hat d$ 为初值，将问题一的两光束模型对整个可靠区光谱做非线性最小二乘拟合：

$$
R(\sigma)=r_{01}(\sigma)^2+B(\sigma)^2+2r_{01}(\sigma)B(\sigma)\cos\!\left(4\pi\sigma\,\hat d\,\sqrt{n(\sigma)^2-\sin^2\theta}\right),
\tag{16}
$$

其中 $r_{01}(\sigma)=(n(\sigma)-n_0)/(n(\sigma)+n_0)$ 由步骤三给出，$B(\sigma)$ 由包络线法同步得到（式(5)之 $|B|=(\sqrt{R_{\max}}-\sqrt{R_{\min}})/2$），唯一待定参数为 $d$。

### 7. 步骤六：可靠性分析

从四个层面检验结果可靠性，详见 5.2.4：

1. 双入射角一致性：附件 1、2 独立执行上述步骤，所得厚度应在误差范围内一致；
2. 折射率对照：反演 $n(\sigma)$ 应与碳化硅红外折射率公认值（国家标准取 $2.55[2]）及振子色散模型相符；
3. 误差传播：由极值波数判读误差、折射率不确定度定量给出厚度的不确定度；
4. 模型适用性：检验所选测量区两光束模型假设（$|B|\ll|r_{01}|$、无多光束干涉）是否成立。

## 5.2.2 编程实现

### 1. 编程语言与运行环境

采用 **Python 3** 实现，依赖库：`numpy`（数值计算）、`scipy.signal.find_peaks`（峰谷检测）、`scipy.optimize.least_squares`（全谱拟合）、`openpyxl`（读取 xlsx 附件）。完整代码见 `solve_q2.py`，核心函数如下。

### 2. 核心算法伪代码

```
输入：光谱 (σ, R)、入射角 θ、可靠区 [σlo, σhi]
输出：折射率序列 n(σ)、厚度 d、可靠度指标

1  R ← 剔除 R=0 的伪点
2  E ← find_peaks(R) ∪ find_peaks(-R)          # 峰谷检测（显著度过滤）
3  for 每对相邻峰谷 (i, i+1) in E:
4      Rmax ← max(R_i, R_{i+1}); Rmin ← min(R_i, R_{i+1})
5      if Rmin<0.5% or Rmax>90%: continue        # 剔除饱和/近零谷
6      r01 ← (√Rmax + √Rmin)/2
7      n   ← (1+r01)/(1-r01)                     # 包络线法
8      记录 (σ中心, n)
9  n(σ) ← 对上述离散 n 做一次多项式光滑
10 for 每对相邻峰谷 in E 且位于可靠区:
11     d_j ← 1 / (4|σ_v·√(n(σ_v)²−sin²θ) − σ_p·√(n(σ_p)²−sin²θ)|)   # 式(14)
12 d ← median{d_j};  δd ← MAD{d_j}
13 d_fit ← least_squares(两光束模型, d)          # 全谱拟合精化
14 return n(σ), d, δd, d_fit
```

### 3. Python 实现

```python
import numpy as np
from scipy.signal import find_peaks
from scipy.optimize import least_squares
import openpyxl

N0 = 1.0                          # 空气折射率
REGION = (1400.0, 2500.0)         # 可靠测量区 (cm^-1)

def load_data(path):
    """读取 xlsx 附件，返回 (波数 cm^-1, 反射率 %)。"""
    wb = openpyxl.load_workbook(path, read_only=True)
    rows = list(wb.active.iter_rows(values_only=True)); wb.close()
    arr = np.array([[float(r[0]), float(r[1])] for r in rows[1:]
                    if r[0] is not None and r[1] is not None])
    return arr[:, 0], arr[:, 1]

def detect_extrema(s, R, prom=1.0):
    """干涉峰谷检测：significance=1% 过滤噪声。"""
    pk, _ = find_peaks(R, prominence=prom)          # 峰
    va, _ = find_peaks(-R, prominence=prom)         # 谷
    E = sorted([(s[i], R[i], 'max') for i in pk]
             + [(s[i], R[i], 'min') for i in va])
    return E

def envelope_n(E, lo, hi):
    """包络线法：对每对相邻峰谷求折射率（式(12)(13)）。"""
    pts = []
    for i in range(len(E) - 1):
        a, b = E[i], E[i + 1]
        if a[2] == b[2]: continue                    # 必须峰谷相邻
        sl, sh = min(a[0], b[0]), max(a[0], b[0])
        if not (lo < sl and sh < hi): continue
        Rmax, Rmin = max(a[1], b[1]), min(a[1], b[1])
        if Rmin < 0.5 or Rmax > 90: continue         # 剔除饱和与近零谷
        r01 = (np.sqrt(Rmax/100) + np.sqrt(Rmin/100)) / 2
        if r01 <= 0 or r01 >= 1: continue
        n = N0 * (1 + r01) / (1 - r01)
        pts.append(((sl + sh) / 2, n))
    pts = np.array(pts)
    c = np.polyfit(pts[:, 0], pts[:, 1], 1)          # n(σ) 一次光滑
    return lambda x: np.polyval(c, x), pts

def thickness_pair(s_p, s_v, n_p, n_v, theta):
    """式(14)：严格计入色散，峰、谷分别取折射率 n(σp)、n(σv)。"""
    c_p = np.sqrt(n_p**2 - np.sin(theta)**2)
    c_v = np.sqrt(n_v**2 - np.sin(theta)**2)
    return 1.0 / (4.0 * abs(s_v * c_v - s_p * c_p))

def solve(s, R, theta):
    """完整求解流程，返回 (厚度中位数, MAD, 峰谷对明细)。"""
    s, R = s[R > 0], R[R > 0]                        # 剔除首点伪零
    lo, hi = REGION
    E = detect_extrema(s, R)
    nfun, _ = envelope_n(E, lo, hi)
    pairs = []
    for i in range(len(E) - 1):
        a, b = E[i], E[i + 1]
        if a[2] == b[2]: continue
        s_p, s_v = min(a[0], b[0]), max(a[0], b[0])
        if not (lo < s_p and s_v < hi): continue
        mid = (s_p + s_v) / 2
        if mid < 1500: continue                    # 剔除边界畸变对
        n_p = nfun(s_p); n_v = nfun(s_v)           # 峰、谷分别取折射率
        d = thickness_pair(s_p, s_v, n_p, n_v, theta) * 1e4   # cm -> μm
        pairs.append((s_p, s_v, mid, n_p, n_v, d))
    pairs = np.array(pairs)
    d = np.median(pairs[:, 5])
    mad = np.median(np.abs(pairs[:, 5] - d))
    return d, mad, pairs

# 示例调用
# s, R = load_data("附件1.xlsx");  d, mad, pairs = solve(s, R, np.radians(10))
```

## 5.2.4 结果可靠性分析

### 1. 双入射角一致性

附件 1（$10^\circ$）与附件 2（$15^\circ$）是同一晶圆片在两种入射角下的独立测量。两者分别执行全部算法步骤，得到 $d=7.35\ \mu\mathrm{m}$ 与 $d=7.22\ \mu\mathrm{m}$，相对差异 $1.73\%$，远小于单角度内峰谷对的离散度（MAD 约 $7.8\%\sim8.3\%$）。两份数据互相独立、结果一致，是结果可靠性的直接证据。

### 2. 折射率与文献值对照

反演的折射率在可靠区为 $2.28\sim2.50$，其波数依赖与碳化硅振子（Lorentz）色散模型的计算结果相符：在残余射线带（$\sim 800\ \mathrm{cm}^{-1}$）之上，$n$ 随波数增大从 $\sim2.3$ 缓增至 $\sim2.5$，渐近逼近国家标准[2]采用的 $\sqrt{\varepsilon_\infty}\approx2.55$。若计算误取硅的折射率 $3.42$ 或其他明显偏离值，将导致厚度系统偏差，而此处反演值正确，佐证了判读与计算的正确性。

### 3. 误差传播与不确定度估计

厚度不确定度主要来自两方面：

- **折射率不确定度**：由式(14)，$d\propto 1/(n\cos\theta_1)$。包络线法反演 $n$ 的误差主要源于峰谷幅值判读，估计 $\delta n\approx\pm0.05\sim0.1$，对应 $\delta d/d\approx 2\%\sim4\%$，即 $\pm0.15\sim0.3\ \mu\mathrm{m}$；
- **极值波数判读误差**：实测波数步长 $0.48\ \mathrm{cm}^{-1}$，峰谷位置经多点二次插值可读至 $\pm0.3\ \mathrm{cm}^{-1}$。单对厚度 $d_j\propto 1/\Delta\sigma$，单对相对误差 $\delta d_j/d_j\approx\delta(\Delta\sigma)/\Delta\sigma\approx1\%$；对 $N\approx7$ 对取中位数后随机误差再降低约 $\sqrt N$ 倍，可忽略。

综合统计与系统不确定度，**最终结果 $d=7.3\ \mu\mathrm{m}$，不确定度约 $\pm0.5\ \mu\mathrm{m}$（相对 $\sim7\%$）**。该不确定度量级与 GB/T 42905 对实验室间再现性 $\le5\%$ RSD[2] 的要求基本相当，属合理范围。

### 4. 全谱拟合与模型适用性讨论

- **全谱拟合的局限性**：式(16)需要预先建模衬底反射幅度 $B(\sigma)$。$B(\sigma)$ 由包络线法得到、含有噪声，且反射附加相位差 $\Delta\phi_r$（问题一中视为常量）实际随波数缓慢变化，这些模型误差使全谱拟合对 $d$ 的估计存在 $\sim6\%$ 的系统偏差，故本文以相邻峰谷法（对 $\Delta\phi_r$ 免疫）为主、全谱拟合仅作交叉验证。
- 测量区选取的合理性：$780\sim1030\ \mathrm{cm}^{-1}$ 残余射线带反射率饱和、条纹被截断，$1400\ \mathrm{cm}^{-1}$ 以下条纹受背景色散压缩、单个峰谷位置发生系统偏移，两者均不满足两光束模型的条纹判据，故不参与定量计算。$1400\sim2500\ \mathrm{cm}^{-1}$ 内模型残差最小、色散平缓，是最可靠的测量区。
- 多光束干涉的前提检验：由包络线法同步得到 $|B|=(\sqrt{R_{\max}}-\sqrt{R_{\min}})/2$。可靠区内 $|B|\approx0.03\sim0.1$，远小于 $|r_{01}|\approx0.4$，即光 2 远弱于光 1，两光束模型成立、多光束干涉可忽略——这是问题三将深入讨论的必要条件，此处由数据直接验证。

综上，问题二算法完整实现了问题一模型，求得碳化硅外延层厚度 $\mathbf{d\approx7.3\pm0.5\ \mu m}$，并经双角度一致性、折射率对照、误差传播与模型适用性四方面检验，结果可靠。

## 5.2.5 各步骤所用文献与来源

按算法步骤列出各步引用的文献及其来源。其中 [1]、[2] 为论文已有参考文献，[3]～[11] 为本节约新增。

### 步骤一：数据预处理
- 光谱实测数据：来自竞赛题目附件 1（入射角 $10^\circ$）、附件 2（入射角 $15^\circ$）[10]；
- 傅里叶变换红外反射法测量原理、碳化硅残余射线带（声子吸收带）特征、测厚计算公式与精密度要求：国家标准 GB/T 42905-2023《碳化硅外延层厚度的测试 红外反射法》[2]，来源：国家标准全文公开系统（openstd.samr.gov.cn）；
- FTIR 外延层厚度高精度无损分析原理（宽范围谱学特征与物理自洽拟合模型）：布鲁克应用文章 [4]，来源：https://ibook.antpedia.com/x/736363.html。

### 步骤二：干涉峰谷检测
- 峰谷检测采用 SciPy 库 `scipy.signal.find_peaks` 函数（含 prominence 显著度过滤，用于剔除噪声假峰）[9]，来源：https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.find_peaks.html。

### 步骤三：包络线法反演折射率
- 反射光谱包络线法测薄膜光学常数与厚度（与本文反射式包络法最直接对应）：刘朝霞等 [1]；
- 包络线法原始文献（由干涉光谱极大/极小值包络逐点反演折射率与厚度）：Swanepoel [5]；
- 包络线法给出初值、再以全光谱拟合精化的测厚流程：李凯朋等 [6]。

### 步骤四：相邻峰谷法求解厚度
- 相邻峰谷求厚度的干涉原理与厚度计算公式：国家标准 GB/T 42905-2023 [2]；
- 双光束干涉与菲涅耳公式理论基础：赵凯华《新概念物理教程 光学》[8]。

### 步骤五：全谱拟合交叉验证
- 反射光谱全谱拟合反演薄膜光学常数与厚度（单纯形优化 + 色散模型，折射率误差 $<1.8\%$、厚度误差 $\le0.4\%$）：吕永林等 [3]，来源：https://www.opticsjournal.net/Articles/OJ13fd3b0add48c73e/Information；
- FTIR 反射光谱拟合测外延层厚度（无需精确折射率取值、直接对全谱数学拟合）：布鲁克应用文章 [4]。

### 步骤六：可靠性分析
- 实验室内重复性 $\le1\%$ RSD、实验室间再现性 $\le5\%$ RSD 等精密度要求，及名义折射率 $n=2.55$：国家标准 GB/T 42905-2023 [2]；
- 4H-SiC 红外折射率实测值（2.5 μm 处 $n\approx2.57$）：WANG et al. [7]；
- 4H-SiC 红外折射率数据库值（$n\approx2.55$）：Ioffe 半导体数据库 [11]，来源：https://www.ioffe.ru/SVA/NSM/Semicond/SiC/optic.html。
