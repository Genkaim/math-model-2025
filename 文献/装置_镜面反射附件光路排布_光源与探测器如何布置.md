# 文献：镜面反射附件的光路排布（光源与接收器如何布置）

## 1 总体光路：光源 → 干涉仪 → 反射附件 → 样品 → 探测器

FTIR（傅里叶变换红外光谱仪）测量反射光谱的完整光路：

```
红外光源（硅碳棒/陶瓷光源，约1200°C）
   ↓
迈克尔逊干涉仪（分束器+动镜+定镜）→ 干涉调制光
   ↓
反射附件（镜面反射附件，决定入射角）
   ↓ 以固定入射角 θ 照射样品表面
样品（外延片）
   ↓ 镜面反射光（反射角 = 入射角 θ）
反射附件（收集反射光）
   ↓
探测器/接收器（DTGS 或液氮冷却 MCT 碲镉汞探测器）
   ↓
计算机 → 干涉图 → 傅里叶变换 → 反射率光谱（波数-反射率）
```

## 2 镜面反射基本原理

- **镜面反射（Specular Reflectance）**：红外光以某一入射角 θ 照射在样品表面，一部分发生反射，**反射角等于入射角**（图1）；另一部分透射入样品，符合斯涅耳定律 n₁sinθ₁ = n₂sinθ₂。
- 反射率 R = |r|² = I_R/I_0，与偏振相关：
  - 平行偏振系数：r‖ = (n₂cosθ₁ − n₁cosθ₂)/(n₂cosθ₂ + n₁cosθ₁)
  - 垂直偏振系数：r⊥ = (n₁cosθ₁ − n₂cosθ₂)/(n₂cosθ₂ + n₁cosθ₁)
- 在分子共振吸收频率处，折射率突变（复折射率 ñ = n + ik），反射率 R 突变；可通过 Kramers–Kronig（KK）变换将反射谱变换为类似吸收谱。

## 3 反射-吸收与外延层测厚的干涉原理（与题目直接相关）

- **反射-吸收测量**：样品放在反射基底上，光**透过样品 → 在基底镜面反射 → 再次透过样品**，得到反射-吸收光谱。光程 L = 2d/cosθ₂（d 为厚度，θ₂ 为样品内折射角）。入射角越大，光程越长，灵敏度越高。
- **干涉条纹测厚**：当样品厚度均匀时，**外延层表面反射光**与**外延层-衬底界面反射光**（经过外延层两次透射）之间相互干涉，在测得光谱中出现**干涉条纹**。根据干涉条纹即可计算样品厚度——**半导体外延层厚度正是采用这种方法测定**。
- 该原理对应题目图1：光源以入射角 θ₀ 照射外延层，R1 为表面反射光，R2 为经衬底界面反射后返回的光，两束光干涉。

## 4 反射附件类型与光源-探测器排布方式

镜面反射测量装置基本结构有三种：**固定角反射附件、可变角反射附件、掠角反射附件**。

### (1) 固定角反射附件
入射角固定，通常有 **10°、30°、45°、70°、80°、85°** 六种；80°/85° 又称掠角反射附件。

- **10° 附件**（与题目附件1/3 的 10° 入射角对应）：
  - 主要用于反射率测量；入射角越小，**偏振效应对反射率的影响越小**。
  - 设计上使产生一个**准直光束**照亮样品区域，使反射率测量以均匀的 10° 入射角进行，尽可能减小偏振影响。
- **30°、45° 附件**（适合厚膜/薄膜测厚）：
  - 入射深度一般在 1 微米以上；光学设计相对简单，红外光利用效率高，对膜厚测量能提供稳定数据。

### (2) 可变角反射附件
- 入射角**连续可调**，范围通常 **30°~80°** 或 **20°~85°**。
- 样品放在旋转样品台上，转动样品台改变入射角，光路保持对齐（聚焦光束始终打在样品同一位置）。
- 题目中同一晶圆片分别以 10° 和 15° 入射测量，即使用可变角反射附件在不同角度下测量。

### (3) 掠角反射附件
- 入射角 80°/85°，入射深度浅（<1 μm），适合纳米级薄膜、单分子膜等。
- 掠角时样品表面红外光斑为椭圆形（如球面镜聚焦光斑直径 2 mm 时，样品表面光斑约 21 mm×2 mm），需样品有足够尺寸；光谱信号弱，推荐液氮制冷 MCT 探测器。

## 5 附件内部光学设计（光源-探测器排布细节）

- **固定角反射附件光路**：红外光束进入附件后经**平面镜/球面镜转折**，以固定角度照射样品；反射光经对称光路收集后返回光谱仪探测系统。
- **可变角反射附件光路**：入射光束在附件内经反射镜转折照射样品（入射角可调），反射光沿对称路径返回探测器，附件内部光程恒定，保证不同角度下测量基准一致。
- **绝对反射附件**：将背景测试用的反射镜集成到样品测量光路中，保持光程一致，排除反射镜影响，用于高反射率样品的绝对反射率测量。
- **背景/参比测量**：用镀金（Au）镜等**高反射、不吸收红外**的表面采集背景光谱，样品反射率按与背景的相对值计算。

## 7 关键要点总结

1. **光源**：FTIR 内置红外光源（硅碳棒），经干涉仪调制后进入反射附件。
2. **接收器/探测器**：DTGS（室温）或 MCT（液氮制冷，高灵敏）；探测反射光谱。
3. **排布核心**：反射附件以**入射角 θ = 反射角** 的对称光路，将光源光束引导到样品表面，并收集镜面反射光到探测器；样品可绕轴旋转改变入射角。
4. **10°~15°入射角的意义**：入射角越小，偏振效应影响越小，反射率测量越接近正常入射；厚度公式中用 √(n²−sin²θ) 修正斜入射影响。
