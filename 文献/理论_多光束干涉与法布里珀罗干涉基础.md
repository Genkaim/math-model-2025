# 理论参考：多光束干涉（法布里-珀罗干涉）基础理论

> 本文档整理自公开教材/百科资料，供问题 3（多光束干涉对厚度计算精度的影响）建模参考。
> 主要来源：百度百科"干涉"条目、北京邮电大学物理实验教学中心法布里-珀罗干涉仪实验原理、《半导体薄膜光谱学》（薛增泉等，平行平板多光束干涉章节）。

## 1 平行平板的多次反射与透射

红外光入射到厚度为 d、折射率为 n 的平行平板（外延层）时，光在平板上下两个界面间发生多次反射和透射，形成一系列反射光束和透射光束。各光束叠加产生**多光束干涉**。

相邻两束反射光/透射光之间的光程差：

```
ΔL = 2·n·d·cosθ'
```

相位差：

```
φ = (2π/λ)·ΔL = 4π·n·d·cosθ' / λ
```

其中 θ' 为光在平板内部的折射角（与外延层表面法线的夹角）。

## 2 艾里（Airy）公式

设平板表面反射率为 R（强度反射率，两界面相同 R₁=R₂=R），则反射光强与透射光强分别为：

**反射光强：**

```
I_r / I_0 = 4R·sin²(φ/2) / [(1-R)² + 4R·sin²(φ/2)]
```

**透射光强：**

```
I_t / I_0 = (1-R)² / [(1-R)² + 4R·sin²(φ/2)]
```

上式即**艾里公式**。可见反射率 R 越大，干涉条纹越尖锐（对比度越高）。

### 2.1 细度（Finesse）

定义：

```
F = 4R / (1-R)²
```

自由光谱范围 FSR 与条纹半高宽之比称为细度：

```
N ≈ π·√R / (1-R)      （R 较高时）
```

反射率越高，细度越高，透射峰越锐利。

## 3 考虑外延层-衬底两界面反射率不同的反射率公式

若空气-外延层界面强度反射率为 R₁，外延层-衬底界面为 R₂，两界面反射率不等（更符合外延层结构），则总反射率为：

```
R_FP = I_R / I_0 = [R₁ + R₂ - 2·√(R₁·R₂)·cosφ] / [1 + R₁ + R₂ - 2·√(R₁·R₂)·cosφ]
```

（推导自对多束反射光复振幅等比级数求和，取模平方。）

## 4 双光束干涉与多光束干涉的关系

- **双光束模型**（问题 1 假设，仅考虑一次反射透射）：
  ```
  R_double = r₀₁² + r₁₂² + 2·r₀₁·r₁₂·cosδ
  ```
  其中 r₀₁、r₁₂ 为界面振幅反射系数，δ 为两束光相位差。

- **多光束模型**（Airy 公式）：
  ```
  R_Airy = [r₀₁² + r₁₂² + 2·r₀₁·r₁₂·cosδ] / [1 + r₀₁²·r₁₂² + 2·r₀₁·r₁₂·cosδ]
  ```
  多光束干涉引入了分母项，使干涉条纹更锐利、对比度更高。

- 当平板反射率 R 很低（如 R<0.1）时，高阶反射光束强度迅速衰减可忽略，多光束干涉退化为双光束干涉。通常认为反射率约 4%（R=0.04）时，前两束反射光占主导，可近似为双光束干涉。

## 5 多光束干涉产生的必要条件

1. **界面反射率足够高**：高阶反射光束振幅需达到总振幅的 3%~5% 以上，即 R₀₁·R₁₂·A ≥ 3%（A 为衰减因子）。
2. **光源相干长度足够大**：相干长度 L_c ≥ 最大有效光程差 2·n₁·d·cosθ₁。
3. **光学厚度与波长同量级**：n₁d ~ λ 时干涉效应最明显。
4. **材料吸收微弱**：复折射率虚部满足 κ₁d ≪ 1，衰减可忽略。

## 6 多光束干涉对厚度测量精度的影响

- 多光束干涉改变干涉条纹的**峰形与对比度**（条纹变尖锐），使双光束模型极值定位产生系统偏差。
- 影响程度与界面反射率、吸收、相干性、光谱仪分辨率有关。
- 可通过 FFT 频谱分析判断多光束效应，或采用 Airy 全谱非线性拟合、光谱滤波修正等方法消除影响。
