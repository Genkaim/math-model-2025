# GB/T 14847-2010《重掺杂衬底上轻掺杂硅外延层厚度的红外反射测量方法》

- **标准号**：GB/T 14847-2010
- **英文名称**：Test method for thickness of lightly doped silicon epitaxial layers on heavily doped silicon substrates by infrared reflectance
- **发布日期**：2010 年；**实施日期**：2011 年
- **标准状态**：现行（被 GB/T 14847-2025 替代，2025 版用于参考）
- **替代标准**：GB/T 14847-1993
- **ICS**：29.045；**CCS**：H80
- **归口单位**：全国半导体设备和材料标准化技术委员会（TC203/SC2）
- **起草单位**：宁波立立电子股份有限公司、信息产业部专用材料质量监督检验中心
- **主要起草人**：李慎重、何良恩、许峰、刘培东、何秀坤

## 1 适用范围

适用于衬底在 23 ℃ 电阻率小于 **0.02 Ω·cm**、外延层在 23 ℃ 电阻率大于 **0.1 Ω·cm**、且外延层厚度大于 **2 μm** 的 n 型和 p 型硅外延层厚度的测量。在降低精度情况下，原则上也适用于测试 **0.5 μm ~ 2 μm** 之间的 n 型和 p 型外延层厚度。

## 2 测量原理

基于衬底和外延层光学常数的差异，试样反射光谱出现连续极大极小特征谱的光学干涉现象。当外延层表面反射的光束和衬底界面反射的光束的光程差是半波长的整数倍时，反射光谱中可观察到干涉极值。

干涉相长条件（波峰）：

```
2·n₁·d·cosθ₁ = m·λ          (m 为整数)
```

干涉相消条件（波谷）：

```
2·n₁·d·cosθ₁ = (m + 1/2)·λ
```

其中 n₁ 为外延层折射率（硅材料通常取 3.42），d 为外延层厚度，θ₁ 为外延层内折射角，λ 为入射光波长。

## 3 仪器设备

### 3.1 红外光谱仪（傅里叶变换红外光谱仪或双光束红外分光光度计）

| 参数 | 要求 |
|---|---|
| 波长范围 | 2 μm ~ 50 μm（常用 6 μm ~ 25 μm） |
| 波长重复性 | 不大于 0.05 μm |
| 波长精度 | ± 0.05 μm |

### 3.2 仪器附件
- 反射附件：入射角不大于 30°
- 掩模：由非反射材料制成，透光孔径不大于 8 mm
- 样品台：构造须确保不会对外延层造成损伤

## 4 试样准备

试样表面应是高度反射的，防止大面积晶格不完整缺陷，除自然氧化层外不应有钝化层。测量前试样表面应进行清洁处理，处理方法不能影响试样外延层厚度。

## 5 操作步骤

### 5.1 光谱仪校准
使用厚度 300 μm ~ 500 μm 的聚苯乙烯膜做标样，以标样的 1601.6 cm⁻¹ 或 648.9 cm⁻¹ 峰为测量参考峰进行校准。将反射附件置于光路中，测量 100% 线，其峰谷值应小于 8%。

### 5.2 测量条件选择
对光栅式红外分光光度计，选取最佳扫描速度；用最慢扫描速度记录波数小于 400 cm⁻¹ 的极小值谱图，分步增加扫描速度并记录极小值位置，所有容许扫描速度对应的极小值位置偏差不超过 ±1 cm⁻¹。

### 5.3 测量执行
小心处理试样，防止对薄外延层表面损伤。将试样置于掩模光路上使目标测量位置对准光束。获得反射光谱后，若峰值振幅与噪声振幅比小于 5，则不能用于计算外延层厚度。通过计算极大值下面或极小值上面满刻度 3% 处的水平线与反射光谱相交的截距平均值，确定反射光谱中每个极值的波数。

### 5.4 衬底电阻率测量
采用 GB/T 1552 规定的方法，在外延层厚度测试位置相对应的反面位置点测量衬底电阻率。

## 6 数据处理与计算

### 6.1 极值波数转换为波长

```
λᵢ = 10000 / σᵢ      （σᵢ 为波数，单位 cm⁻¹；λᵢ 为波长，单位 μm）
```

### 6.2 极值级数计算

```
Pₓ = (m·λ₂ + φ₁·λ₂ - φ₂·λ₁) / (λ₁ - λ₂)
```

其中 Pₓ 为极值级数，φ₁、φ₂ 为相移，m 为两极值间的级数差，λ₁、λ₂ 为极值波长。

### 6.3 厚度计算

```
T = [Pᵢ - (φ₁ + φ₂)/(4π)] × λᵢ / (2·n·cosθ)
```

其中 n 为外延层折射率（硅材料 n = 3.42），θ 为外延层上光束入射角。

## 7 干扰因素控制

| 干扰因素 | 控制措施 |
|---|---|
| 表面晶格不完整 | 确保试样表面无大面积缺陷 |
| 掩模孔材料和孔径 | 使用非反射材料，控制孔径尺寸 |
| 杂散光 | 优化探测器设置 |
| 环境因素 | 控制静电、噪声、振动及温湿度稳定性 |

## 8 精密度要求

- 单台设备重复性：91% 的测试结果好于 1%（R2S%），所有测试结果好于 2%
- 多设备测量再现性：估计范围为 0.27% ~ 15.44%（R2S%）

## 9 试验报告内容

试验报告应包括：实验室和操作人员名称、测试日期、测试硅片编号、衬底导电类型和电阻率、外延层导电类型和电阻率、红外仪器的波数范围、掩模孔径、波数扫描速度、试样图示测量位置、所用的极值和级数、计算出的厚度及平均厚度值。
